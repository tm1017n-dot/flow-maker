# Flow Maker

担当・部署間の業務フロー図を、Windows 11のブラウザで作るオフラインの試作版です。外部サービス、サーバー、追加パッケージは実行時に必要ありません。

## 試す方法

このリポジトリの `index.html`、`styles.css`、`app.js` を同じフォルダに置き、`index.html` をブラウザで開きます。サンプルの申請受付フローが表示されます。ChromeまたはEdgeの現行版を想定しています。

## 主な操作

1. 左のパレットから図形を追加し、ドラッグして位置を調整します。
2. 図形を選択し、右側で文言と担当レーンを編集します。担当レーンの見出しをクリックすると、名称や順序を変更できます。
3. 作業などを選択して「つなぐ」を押し、接続先をクリックします。判断の矢印を選択すると、分岐条件を入力できます。
4. 帳票・システムは「作業に関連付ける」で補助線を引けます。
5. 「保存」で編集用のJSONファイルをダウンロードします。「開く」で再編集できます。PNGは直接保存し、PDFはブラウザの印刷画面から「PDFに保存」を選びます。

変更中はブラウザ内に復旧用データを一時保存します。次回起動時に復旧するか選べます。**復旧用データは編集用ファイルではありません**。ブラウザのデータを消すと失われるため、作業の区切りでJSONを保存してください。

## 試作段階の範囲

- 図形は開始・終了、作業、判断、帳票、システム。担当レーンは最大12、図は1ページです。
- 矢印は接続先に追従しますが、経路を個別に曲げる操作は未実装です。交差の多い図では線が重なる場合があります。
- PNG・PDFの文字の大きさは、出力前にプレビューと保存結果を確認してください。PDF出力はブラウザの印刷機能を利用します。
- 同一の帳票やシステムを複数作業に関連付けられますが、個別の関連付けを外す画面は未実装です。
- 共同編集とクラウド同期はありません。保存時はブラウザのダウンロード動作に従うため、既存のJSONを自動で上書きしません。
