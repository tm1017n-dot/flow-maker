# Flow Maker

担当・部署間の業務フロー図を、Windows 11のブラウザで作るオフラインの試作版です。外部サービス、サーバー、追加パッケージは実行時に必要ありません。

## 試す方法

このリポジトリの `index.html`、`styles.css`、`app.js` を同じフォルダに置き、`index.html` をブラウザで開きます。サンプルの申請受付フローが表示されます。ChromeまたはEdgeの現行版を想定しています。

## 主な操作

1. 左のパレットから図形を追加し、ドラッグして位置を調整します。
2. 図形を選択し、右側で文言と担当レーンを編集します。担当レーンの見出しをクリックすると、名称や順序を変更できます。
3. 作業などを選択して「つなぐ」を押し、接続先をクリックします。判断の矢印を選択すると、分岐条件を入力できます。矢印の白い丸をドラッグして経路を調整し、条件ラベルも直接移動できます。右側では接続する辺、折れ線の位置、ラベルの移動量を指定できます。
4. 帳票・システムは「作業に関連付ける」で補助線を引けます。補助線をクリックすると、右側で個別に解除できます。
5. 「保存」で編集用のJSONファイルをダウンロードします。「開く」で再編集できます。PNGは直接保存し、PDFはブラウザの印刷画面から「PDFに保存」を選びます。

保存ボタンはJSONのダウンロードを開始します。画面の時刻はダウンロードを開始した時刻であり、実際の保存完了を検知したものではありません。保存先にファイルがあることを確認してください。

変更中はブラウザ内に復旧用データを一時保存します。次回起動時に復旧するか選べます。**復旧用データは編集用ファイルではありません**。ブラウザのデータを消すと失われるため、作業の区切りでJSONを保存してください。

## 試作段階の範囲

- 図形は開始・終了、作業、判断、帳票、システム。担当レーンは最大12、図は1ページです。
- 矢印は接続先に追従します。接続する辺と1本の折れ線の位置を調整できます。複数の任意の経由点を追加する機能と自動の障害物回避はありません。
- PNG・PDFの文字の大きさは、出力前にプレビューと保存結果を確認してください。PDF出力はブラウザの印刷機能を利用します。
- 同一の帳票やシステムを複数作業に関連付けられます。補助線ごとに解除できます。
- 共同編集とクラウド同期はありません。保存時はブラウザのダウンロード動作に従うため、既存のJSONを自動で上書きしません。

## 2026-09-30の修正

1. 保存・読込・図の切替時に古い一時保存の予約を取り消し、画面を閉じる直前にも未保存データを記録します。
2. 中間レーンの削除時に、その後のレーンと図形の位置を一緒に詰めます。
3. 出力には選択枠、矢印の強調色、編集用ハンドルを含めません。
4. 読込時にIDの重複、項目の型、接続先、サイズなどを検証します。読込に失敗しても現在の図を維持します。
5. 保存状態を実際のダウンロード操作に合わせて表示します。保存後に元の状態へ戻した場合も未保存状態を判定し直します。
6. 矢印の接続する辺、折れ線の位置、条件ラベルの位置を調整できます。「自動配置に戻す」で解除できます。
7. 図形と条件の文言は省略せず、改行と折り返しで全文を表示します。図形は高さを自動調整し、幅・最低の高さ・文字サイズも変更できます。

以前の編集用JSONも読み込めます。追加された配置設定はJSONに保存されます。

## 検証

Node.jsが利用できる開発環境では `node tests/regression.cjs` で回帰チェックを実行できます。これは保存と読込、配置、出力SVG、入力操作などのロジック検証であり、実ブラウザの描画・ダウンロード・印刷の検証を代替するものではありません。Windows 11のブラウザで、図形とハンドルのドラッグ、日本語の表示、PNG・PDF出力を別途確認してください。

## 追加の編集・出力機能（2026-09-30）

- 左方向の矢印は、自動配置で図形の左辺から出て接続先の右辺へ入ります。判断の「あり／なし」に固定の接続辺はありません。右側の接続位置設定で任意に変えられます。
- 担当レーンをクリックしてから図形を追加すると、そのレーンに置かれます。「配置位置を指定」でキャンバス上の場所をクリックし、パレットで種類を選ぶ方法も使えます。
- 接続中は接続元を強調し、予定線と接続可能な候補を表示します。矢印の編集パネルで接続元・接続先の図形を変更できます。
- Shift＋クリックで複数の図形を選択し、一緒に移動・整列できます。左右揃えは同じ担当レーン内で行います。「縦に等間隔」は3件以上を選びます。位置合わせは10単位のグリッドと近くの図形の中心線を使い、ツールバーで解除できます。
- 上部の「図形パネル」「編集パネル」で左右を折りたためます。「全体表示」は40%未満の倍率でも図全体を収めます。
- PNG・PDFは用紙サイズ、余白を反映した同じページ構成で出力します。PNGは150／300dpiを選べます。印刷時の最小文字サイズが8pt未満の場合は知らせます。これらの設定はJSONにも保存します。
- 「点検」で未接続の作業、条件のない判断の矢印、図形の重なり、未関連の帳票・システムなどを確認できます。警告をクリックすると該当箇所を選択します。警告があっても編集や出力はできます。

[Windowsでのブラウザ確認手順](docs/browser-check.md)。実ブラウザのPNG・PDF出力と操作の確認は、ロジック検証と分けて行います。

## 矢印の直接操作・UI整理（2026-10-01）

- 矢印の線を直接ドラッグできます。縦の部分は左右に、横の部分は上下に動かして経路を調整します。接続元と接続先の図形はそのままです。
- 矢印を選ぶと両端に丸が表示されます。丸を図形の周囲へドラッグすると、接続する辺とその辺の中での位置を変更できます。条件ラベルも直接ドラッグできます。
- 接続端の位置はJSONに保存され、元に戻す操作にも対応します。出力に編集用の丸や強調色は含めません。
- 空白をドラッグしてキャンバスを移動できます。操作方法は「操作ガイド」から確認できます。
- 保存・出力、表示倍率・パネル表示、作図の補助を別々の行に整理しました。右側の細かな設定は折りたたみ、基本操作を先に表示します。
- 狭い画面では操作ボタンを折り返し、編集パネルを下へ移します。モーダル内のボタンも折り返すため、幅の狭い画面で横にはみ出しにくくしています。

検証: 矢印本体・接続端・ラベルの移動、Undo、JSON読込、出力からの編集表示除外、キャンバス移動を回帰チェックで確認しています。HTMLの構造と操作コントロールの存在も検証しました。実ブラウザの画面表示は開発環境のブラウザポリシーでブロックされているため、見た目の最終確認は未完了です。

## ブラウザの縮尺変更への対応

- サイドバーのアイコンと追加ボタンの大きさを固定し、長い説明文は折り返します。高さが不足する場合はパネル内をスクロールできます。
- 画面の有効幅が1100 CSS px以下になると、編集パネルは図の下へ移ります。760 CSS px以下では図形パネルが上段の2列表示になり、400 CSS px以下では1列になります。ブラウザの拡大・縮小でも、この配置へ切り替わります。
- 高さが小さい画面ではページ全体をスクロールでき、ヘッダーやパネルで作図領域が潰れないようにしています。
- 「図の倍率」はキャンバス内の拡大・縮小です。ブラウザの倍率と独立しています。画面幅やパネル表示を変えた後は「全体表示」で図を収め直せます。
- 保存・出力ボタン、倍率コントロール、図形ボタンは文字サイズを縮めずに折り返します。ダイアログも画面内をスクロールできます。

CSSの重複した画面幅指定を整理しました。既存操作の回帰チェックとHTML/CSSの構造を確認しています。ブラウザ倍率ごとの実際の表示確認は未完了です。確認条件は [ブラウザ確認手順](docs/browser-check.md) に記載しています。
