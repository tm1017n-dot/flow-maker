# Flow Maker — 業務マニュアル試作版

このブランチ `feat/manual-prototype` は、確定したフロー図ツールv1.0に、文章中心のマニュアル機能を追加した試作です。確定版は [main](https://github.com/tm1017n-dot/flow-maker/tree/main) に残しています。

Windows 11のブラウザでオフライン利用できます。実行時の外部通信・サーバー・追加パッケージは不要です。

## 起動と試し方

リポジトリをこのブランチでダウンロードし、次の5ファイルを同じフォルダに置いて `index.html` を開きます。

- index.html
- styles.css
- app.js
- manual.css
- manual.js

1. 上部の「手順」を選びます。
2. 「入力例付きで試す」で、現在のフローから説明付きのマニュアルを作れます。実際の文書は「このフローから作成」で空欄から始められます。
3. 左で章または手順を選び、中央で編集します。作業名・担当・分岐条件はフローから参照されます。
4. 「プレビュー」で目次・全体図・本文を確認します。「この手順を編集」で編集に戻れます。
5. 上部の「保存」で、フローとマニュアルをまとめた編集用JSONを保存します。
6. プレビューの「HTMLを保存」で、単体でオフライン閲覧できる文書を出力します。「PDFを印刷・保存」でA4縦の複数ページ文書を印刷／PDF保存できます。

入力例は試作のサンプルです。実際の業務手順・条件に書き換えてください。

## 追加した機能

- 「フロー／手順／プレビュー」の切替。手順は広い入力欄で編集し、狭い画面では一覧を上段へ移します。
- 作業ごとの目的、準備、実施手順、確認項目、完了条件、注意事項、例外対応。
- 図に対応しない概要・用語などの説明項目。
- 章の追加・名称変更・並べ替え、項目の掲載章・掲載順・掲載／非掲載。
- 掲載順と独立した手順番号。章や項目の移動で番号を勝手に変更しません。
- 本文・見出しの検索、必須欄の未記入表示、番号重複・図形との対応切れの表示。
- 図形の「手順を編集」から本文へ、本文の「図で見る」から図形へ移動。
- 担当、条件、接続先、使用する帳票・システムを共通データから表示。
- 図形を削除しても本文を保持。章の削除時は項目を隣の章へ移します。本文の削除は別操作です。
- HTML／PDFの目次と分岐先へのリンク。図の出力とマニュアルの出力を区別しています。
- 手順編集もUndo／Redo、JSON保存・復旧、ライト／ダークに対応。

「図の作業を取り込む」で、後から追加した作業・判断を手順へ取り込めます。既存の本文は書き換えません。実施手順・確認項目は1行1項目で入力すると、プレビューで番号付きの一覧になります。

## 保存形式と互換性

旧フローJSON（version 1）を開けます。マニュアルを作成すると新形式（version 2）となり、本文・章・掲載順も保存します。**マニュアルを含むversion 2は確定版v1.0では開けません。この試作版で再編集してください。**

マニュアルを作成していない図はversion 1のまま保存します。復旧用の保存先キーも確定版と分けています。ブラウザ内の一時保存は編集用JSONの代わりではありません。

保存表示はダウンロード開始を示します。保存先にファイルがあることを確認してください。編集用ファイルの上限は20MB、章は50、マニュアル項目は300、各本文欄は6000文字です。入力欄ではブラウザの通常の文字Undo、入力欄の外では図と手順を含むUndo／Redoを使います。

## 作図機能

v1.0の図形・レーン・矢印・帳票／システム、直接ドラッグ、整列、図のJSON・PNG／PDF出力を維持しています。上部の「図を出力」はフロー図を1ページで出力し、プレビュー内のPDFボタンはマニュアルを複数ページで出力します。PNG／PDFと閲覧用HTMLは白背景です。

## 今回の範囲

文章中心の最小版です。画像挿入、Word出力、正式な改訂履歴、複数業務の管理は、[機能追加案](docs/manual-extension-plan.md)の次段階として残しています。

## 検証

`node --check app.js`、`node --check manual.js`、`node tests/regression.cjs` で検証できます。作図の回帰に加え、手順の生成・編集と履歴、名称連動、章操作、JSONの検証・復元、安全なHTML生成、本文の保持を確認しています。UIと生成HTMLのタグ構造・IDの重複、CSSの構造も確認しました。

実ブラウザによる見た目・ホイール・マウス操作・実際のダウンロード・複数ページ印刷は未確認です。[試作の確認項目](docs/manual-prototype.md)と[既存のブラウザ確認手順](docs/browser-check.md)を参照してください。
