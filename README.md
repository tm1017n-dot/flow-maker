# Flow Maker

担当・部署間の業務フロー図を、Windows 11のブラウザで作るオフラインの試作版です。外部サービス、サーバー、追加パッケージは実行時に必要ありません。

## 試す方法

このリポジトリの `index.html`、`styles.css`、`app.js` を同じフォルダに置き、`index.html` をブラウザで開きます。サンプルの申請受付フローが表示されます。ChromeまたはEdgeの現行版を想定しています。

## 主な操作

1. 左のパレットから図形を追加し、ドラッグして位置を調整します。
2. 図形を選択し、右側で文言と担当レーンを編集します。担当レーンの見出しをクリックすると、名称や順序を変更できます。
3. 作業などを選択して「つなぐ」を押し、接続先をクリックします。判断の矢印を選択すると、分岐条件を入力できます。矢印の白い丸をドラッグして経路を調整し、条件ラベルも直接移動できます。右側では接続する辺、折れ線の位置、ラベルの移動量を指定できます。
4. 帳票・システムは「作業に関連付ける」で補助線を引けます。
5. 「保存」で編集用のJSONファイルをダウンロードします。「開く」で再編集できます。PNGは直接保存し、PDFはブラウザの印刷画面から「PDFに保存」を選びます。

保存ボタンはJSONのダウンロードを開始します。画面の時刻はダウンロードを開始した時刻であり、実際の保存完了を検知したものではありません。保存先にファイルがあることを確認してください。

変更中はブラウザ内に復旧用データを一時保存します。次回起動時に復旧するか選べます。**復旧用データは編集用ファイルではありません**。ブラウザのデータを消すと失われるため、作業の区切りでJSONを保存してください。

## 試作段階の範囲

- 図形は開始・終了、作業、判断、帳票、システム。担当レーンは最大12、図は1ページです。
- 矢印は接続先に追従します。接続する辺と1本の折れ線の位置を調整できます。複数の任意の経由点を追加する機能と自動の障害物回避はありません。
- PNG・PDFの文字の大きさは、出力前にプレビューと保存結果を確認してください。PDF出力はブラウザの印刷機能を利用します。
- 同一の帳票やシステムを複数作業に関連付けられますが、個別の関連付けを外す画面は未実装です。
- 共同編集とクラウド同期はありません。保存時はブラウザのダウンロード動作に従うため、既存のJSONを自動で上書きしません。

## 2026-09-30の修正

1. 保存・読込・図の切替時に古い一時保存の予約を取り消し、画面を閉じる直前にも未保存データを記録します。
2. 中間レーンの削除時に、その後のレーンと図形の位置を一緒に詰めます。
3. 出力には選択枠、矢印の強調色、編集用ハンドルを含めません。
4. 読込時にIDの重複、項目の型、接続先、サイズなどを検証します。読込に失敗しても現在の図を維持します。
5. 保存状態を実際のダウンロード操作に合わせて表示します。保存後に元の状態へ戻した場合も未保存状態を判定し直します。
6. 矢印の接続する辺、折れ線の位置、条件ラベルの位置を調整できます。「自動配置に戻す」で解除できます。
7. 図形と条件の文言は省略せず、改行と折り返しで全文を表示します。図形は高さを自動調整し、幅・最低の高さ・文字サイズも変更できます。

以前の編集用JSONも読み込めます。追加された配置設定はJSONに保存されます。

## 検証

Node.jsが利用できる開発環境では `node tests/regression.cjs` で7項目の回帰チェックを実行できます。これは保存と読込、配置、出力SVG、入力操作などのロジック検証であり、実ブラウザの描画・ダウンロード・印刷の検証を代替するものではありません。Windows 11のブラウザで、図形とハンドルのドラッグ、日本語の表示、PNG・PDF出力を別途確認してください。
