# Flow Maker — 基本機能確定版 v1.0

担当・部署ごとの業務フロー図を、Windows 11のブラウザで作成するオフラインツールです。実行時のサーバー、外部通信、追加パッケージは不要です。

## 起動

`index.html`、`styles.css`、`app.js` を同じフォルダに置き、`index.html` をChromeまたはEdgeで開きます。初回はサンプルを表示します。変更前に保存したJSONも引き続き読み込めます。JSONの形式バージョンは1のままです。

## 作図・編集

1. 担当レーンをクリックし、図形パネルから開始・終了、作業、判断、帳票、システムを追加します。「配置位置を指定」で場所を先に選ぶこともできます。
2. 図形をドラッグして移動し、編集パネルで文言・担当・補足メモを変更します。長文は改行・折り返しで全文を表示し、必要な高さへ広がります。幅・最低の高さ・文字サイズも変更できます。
3. 作業や判断を選び「つなぐ」を押して、接続先をクリックします。矢印を選ぶと条件を入力できます。
4. 矢印の縦の線は左右、横の線は上下へドラッグして経路を調整します。両端の丸は接続辺と辺内の位置、条件ラベルは文字の位置を調整します。「自動配置に戻す」で調整を解除できます。
5. 帳票・システムは「作業に関連付ける」で破線を引きます。破線を選ぶと個別に解除できます。
6. Shift＋クリックで複数選択し、まとめて移動・整列できます。左右揃えは同じ担当レーン内、縦の等間隔は3件以上で行います。
7. レーンの見出しを選ぶと名称・順序を編集できます。レーン内の図形と、両端が一緒に動く矢印の手動経路も追従します。

空白のドラッグで画面を移動します。位置合わせは10単位のグリッドと近くの図形の中心線を使用し、ボタンで解除できます。「点検」は未接続、分岐条件の不足、図形の重なりなどを表示します。警告から対象を選択できます。警告は編集・出力を止めません。

## 表示・操作

- 上部の「ライト」「ダーク」で画面全体の表示を切り替えます。図の編集画面もテーマに合わせて配色が変わります。設定はブラウザ内に保存し、次回の起動時に復元します。図のJSON・保存状態・Undo履歴には含めません。PNG・PDFと出力プレビューは白背景のままです。
- キャンバス外側の余白を10px程度広げました。余白でホイールを動かすとページをスクロールできます。キャンバス・パネル内でもスクロール端に達するとページへスクロールを引き継ぎます。

- キャンバス枠は最低680 CSS px。大きい画面では画面高に合わせて伸びます。上部の標語・装飾見出しは削除し、操作案内を下部に集約しました。高さが足りない画面ではページをスクロールできます。
- 有効幅1100 CSS px以下で編集パネルを下段へ、760 CSS px以下で図形パネルを上段2列へ、400 CSS px以下で1列へ移します。キャンバスの高さはこの切り替えでも維持します。
- サイドバーのアイコンと追加記号は縮まず、説明文は折り返します。パネル内に収まらない項目はスクロールして操作できます。
- 「図の倍率」はキャンバス内の倍率です。ブラウザの倍率とは独立しています。「全体表示」で現在の作図領域に収め直せます。「図形を隠す」「編集を隠す」で横の作図領域を広げられます。
- Ctrl＋SでJSON保存、Ctrl＋Zで元に戻す、Ctrl＋YまたはCtrl＋Shift＋Zでやり直し、Deleteで選択対象の削除。入力欄とダイアログには作図の削除・履歴操作を適用しません。Escで配置・接続モードを取り消せます。

## 保存・出力

「保存」で編集用JSONをダウンロードし、「開く」で再編集します。保存表示の時刻はダウンロード開始時刻です。OS上の保存完了は検知できないため、保存先にファイルがあることを確認してください。

編集中はブラウザ内へ復旧用データを一時保存します。次回起動時に復旧するか選べます。復旧用データはブラウザのデータ削除で失われるため、作業の区切りでJSONを保存してください。

PNGはA4／A3横、余白0～30mm、150／300dpiで出力します。PDFは同じページ構成を印刷画面から保存します。印刷画面ではヘッダー・フッターを無効にしてください。選択枠・ハンドル・接続予定線は出力に含めません。文字が印刷時8pt未満になる場合は知らせます。

## 現時点の範囲

- 画面から追加できる担当レーンは最大12です。互換性のため、読込時は最大30レーン・1000図形・3000矢印を受け付けます。主な利用規模は10～30図形程度を想定しています。
- 図は1ページです。矢印は直角の折れ線で、複数の任意の経由点や障害物の自動回避はありません。
- 共同編集・クラウド同期はありません。保存はブラウザのダウンロードに従い、既存JSONを自動上書きしません。

## 総点検・検証（2026-10-01）

今回を基本機能の確定版として区切ります。状態初期化、Undo／Redo、パネル開閉、レーン位置の再計算を共通化し、未使用処理・廃止したUIのCSSを整理しました。点検時の図形寸法計算も共通化しています。

修正した不具合:

- 図の切り替えやUndo後に、配置・接続モードや配置マーカーが残る。
- Shiftで主選択を解除すると、残った選択とは別の図形を編集する。
- レーン並べ替えで、図形だけ移動し手動経路の位置が取り残される。
- 操作ガイドなどのダイアログ越しに、背後の図をDeleteで削除できる。
- 長いレーン見出しの重なり判定が、実際の見出し高さと一致しない。
- PNGの読み込み中に出力設定を変更すると、画像と寸法の条件がずれる。PNG変換・ダウンロード失敗時の復帰も統一した。

`node --check app.js`、`node tests/regression.cjs` で検証できます。回帰チェックは保存・復旧、JSON検証、ドラッグ、Undo、配置、選択、レーン移動、出力SVG、PNGの設定固定と失敗処理などを対象とします。HTML/CSSの構造も確認しています。

実ブラウザの描画・マウス操作・日本語フォント・実際のダウンロード・印刷の確認は、開発環境の制約により未完了です。確定版は実機検証完了を意味しません。[ブラウザ確認手順](docs/browser-check.md) に未確認の条件をまとめています。

[初期の要件・画面設計](docs/requirements-and-ui.md) は設計の背景資料です。現在の操作と範囲はこのREADMEを参照してください。
