# Flow Maker — 業務マニュアル試作版

このブランチ `feat/manual-prototype` は、確定したフロー図ツールv1.0に、マニュアルの作成・点検・資料追加を備えた試作です。確定版は [main](https://github.com/tm1017n-dot/flow-maker/tree/main) に残しています。

Windows 11のブラウザでオフライン利用できます。実行時の外部通信・サーバー・追加パッケージは不要です。

## 起動と試し方

リポジトリをこのブランチでダウンロードし、ZIP全体を展開し、`index.html` または `Launch.vbs` を開きます。Windowsへの配置は `Install.vbs` を実行します。アプリ本体とアイコンは次の構成です。

- index.html
- styles.css
- app.js
- manual.css
- manual.js
- assets/flow-maker.svg、assets/flow-maker.ico

1. 上部の「手順」を選びます。
2. 「入力例付きで試す」で、現在のフローから説明付きのマニュアルを作れます。実際の文書は「このフローから作成」で空欄から始められます。
3. 全画面共通のサイドバーで章または手順を選び、広い編集欄で編集します。作業名・担当・分岐条件はフローから参照されます。
4. 「次の未記入へ」で入力が必要な項目へ進み、「文書を点検」で未記入・番号・対応切れ・条件を確認します。手順名を押すと編集できます。
5. 「プレビュー」で目次・全体図・本文を確認します。「この手順を編集」で編集に戻れます。
6. 上部の「保存」で、フローとマニュアルをまとめた編集用JSONを保存します。
7. プレビューの「HTMLを保存」で、単体でオフライン閲覧できる文書を出力します。「PDFを印刷・保存」でA4縦の複数ページ文書を印刷／PDF保存できます。

入力例は試作のサンプルです。実際の業務手順・条件に書き換えてください。

## 作図操作の配置

作図の追加操作はキャンバス上部に置いています。「追加先の担当」を選び、「＋ 作業」「判断」をクリックします。開始・終了、帳票、システムは「その他の図形」から追加できます。「＋ 担当レーン」も同じ場所にあります。

「配置位置を指定」を使うと、キャンバスをクリックしてから種類を選べます。マニュアルがある文書では、作業・判断の追加や図形の複製と同時に対応する手順を作成します。図と手順は1回のUndoでまとめて戻せます。手順が300件の場合は追加を止めて案内します。

サイドバーは章・手順の移動と文書情報に使います。「章一覧を隠す」で作業領域を広げられます。フロー／プレビューからも一覧を選んで本文の編集へ移動できます。章・説明の追加は手順の編集画面を開きます。

## Windowsのアイコン・ショートカット

`Install.vbs`は管理者権限不要でアプリを配置し、デスクトップとスタートメニューに **Flow Maker Manual** のショートカットを作ります。`assets/flow-maker.ico`を専用アイコンに使います。展開フォルダから直接起動する`Launch.vbs`も同梱しています。詳しくは [Windowsへの配置と起動](docs/windows-install.md) を参照してください。

キーボードでは `Ctrl+S` で編集用JSONを保存、入力欄の外で `Ctrl+Z`／`Ctrl+Y` でUndo／Redo、`Esc`で接続操作を中止できます。上部のタブは左右矢印キーでも移動できます。

## 追加した機能

- 「フロー／手順／プレビュー」の切替。手順は広い入力欄で編集し、狭い画面では文書サイドバーを上段へ移します。
- 作業ごとの目的、準備、実施手順、確認項目、完了条件、注意事項、例外対応。
- 図に対応しない概要・用語などの説明項目。
- 章の追加・名称変更・並べ替え、項目の掲載章・掲載順・掲載／非掲載。
- 掲載順と独立した手順番号。章や項目の移動で番号を勝手に変更しません。
- 本文・見出しの検索、必須欄の未記入表示、番号重複・図形との対応切れの表示。
- 図形の「手順を編集」から本文へ、本文の「図で見る」から図形へ移動。
- 担当、条件、接続先、使用する帳票・システムを共通データから表示。
- 図形を削除しても本文を保持。章の削除時は項目を隣の章へ移します。本文の削除は別操作です。
- HTML／PDFの目次と分岐先へのリンク。図の出力とマニュアルの出力を区別しています。
- 手順編集もUndo／Redo、JSON保存・復旧、ライト／ダークに対応。

「図の作業を取り込む」で、後から追加した作業・判断を手順へ取り込めます。既存の本文は書き換えません。実施手順・確認項目は1行1項目で入力すると、プレビューで番号付きの一覧になります。

## 迷わず作成するための追加機能

- 作成の順序、記載状況、編集用JSONと配布用HTML／PDFの違いを常に案内します。
- 点検結果から該当手順へ移動でき、未記入の手順を順に開けます。番号重複、空の見出し・章、未登録の作業、空の分岐条件も確認します。
- 手順にPNG／JPEGを追加し、説明文を編集・削除できます。画像もJSONと閲覧用HTMLへ埋め込み、別PCで欠けない構成にしています。
- 「参考資料」に1行1件で資料名を記載できます。`資料名 | https://example.com` の形式でリンクを作れます。共有フォルダの場所は文字で記載してください。
- 作成者・確認者・更新日・改訂内容を設定し、配布文書にも載せられます。確認者は手入力の情報で、承認機能ではありません。
- 手順の複製で本文・画像・資料を再利用できます。複製は独立した説明として作成し、新しい番号を割り当てます。図との対応が切れた手順は、未登録の作業へ再接続できます。
- 検索結果がない場合の案内、先頭・末尾の移動ボタンの無効化、入力時の警告更新を追加しました。

画像は1枚1MB以下・1項目6枚まで、全画像は約8MBまでです。SVGは取り込みません。個人情報を含む画面は、加工した画像を追加してください。大きな文書ではUndo／Redoの保持件数を容量に応じて制限し、少なくとも直前の操作を保持します。ブラウザの容量によって自動復旧ができない場合は案内を表示します。編集用JSONをこまめに保存してください。

## 保存形式と互換性

旧フローJSON（version 1）を開けます。マニュアルを作成すると新形式（version 2）となり、本文・章・掲載順も保存します。**マニュアルを含むversion 2は確定版v1.0では開けません。この試作版で再編集してください。**

マニュアルを作成していない図はversion 1のまま保存します。復旧用の保存先キーも確定版と分けています。ブラウザ内の一時保存は編集用JSONの代わりではありません。

保存表示はダウンロード開始を示します。保存先にファイルがあることを確認してください。編集用ファイルの上限は20MB、章は50、マニュアル項目は300、各本文欄は6000文字です。入力欄ではブラウザの通常の文字Undo、入力欄の外では図と手順を含むUndo／Redoを使います。

## 作図機能

v1.0の図形・レーン・矢印・帳票／システム、直接ドラッグ、整列、図のJSON・PNG／PDF出力を維持しています。上部の「図を出力」はフロー図を1ページで出力し、プレビュー内のPDFボタンはマニュアルを複数ページで出力します。PNG／PDFと閲覧用HTMLは白背景です。

## 今回の範囲

画像・資料・点検・改訂情報まで追加しています。Word出力、過去版の管理を含む正式な改訂履歴、複数業務の管理は、[機能追加案](docs/manual-extension-plan.md)の次段階として残しています。

## 検証

`node --check app.js`、`node --check manual.js`、`node tests/regression.cjs`、`node tests/package.cjs` で検証できます。作図の回帰に加え、手順の生成・編集と履歴、名称連動、章操作、JSONの検証・復元、安全なHTML生成、本文の保持を確認しています。追加機能は、画像の容量・形式・文書切替時の混入防止、複製、再接続、資料の安全なリンク、更新日、画像を含む履歴の容量制限も確認しています。UIと生成HTMLのタグ構造・IDの重複、CSSの構造も確認しました。

Windows上でのVBS実行・ショートカット起動、および実ブラウザによる見た目・ホイール・マウス操作・実際のダウンロード・複数ページ印刷は未確認です。[試作の確認項目](docs/manual-prototype.md)と[既存のブラウザ確認手順](docs/browser-check.md)を参照してください。
