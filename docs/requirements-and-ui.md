# 業務フロー図作成ツール 要件・画面設計 v1.1

更新日: 2026-09-28  
状態: 初版の設計案。実装前に画面試作で操作感を確認する。

## 1. 目的と前提

担当・部署ごとの作業、判断、引き渡しを、1ページの業務フロー図にまとめる。利用者は個人PCで作図し、図をPNGまたはPDFとして資料に貼り付ける。後日の修正のため、編集用データも図ごとに保存する。

| 項目 | 決定事項 |
| --- | --- |
| 利用環境 | Windows 11のブラウザ。個人利用 |
| 標準的な規模 | 数部署、作業10～30件程度、1ページ |
| 図の向き | 担当・部署のレーンを縦列に置き、左から右に進む |
| 作成方法 | 図形を画面上に配置し、矢印で接続する |
| 出力 | PNGとPDF |
| 保存 | 図ごとの編集用ファイル。ブラウザ内の一時保存による復旧も行う |
| 接続 | 分岐、条件付き矢印、分岐後の合流を扱う |
| 補足情報 | 帳票・システムを作業とは区別して表す |

初版は共同編集、ログイン、外部サービスとの連携、業務手順の実行を扱わない。

## 2. 図の表現ルール

- **レーン**: 担当・部署を表す縦列。同じ担当の図形はそのレーン内に置く。境界をまたぐ矢印が引き渡しを表す。
- **開始・終了**: 業務の入口と出口。
- **作業**: 担当者が行う行為。短い動詞を含む文を推奨する（例: 「申請内容を確認する」）。
- **判断**: 条件による分岐。出ていく矢印に「不備あり」「不備なし」などの条件を書く。複数の矢印を一つの後続作業に合流させられる。
- **帳票・システム**: 補足図形として作業に関連付ける。業務の進行を示す矢印の接続先とは区別し、作業との関係を細い補助線などで示す。図形には名称を記す。
- **矢印**: 進行方向を示す。接続先を移動しても端点は追従する。線の経路を利用者が調整できる。交差や重なりは可能な範囲で見分けやすくする。
- **表示順**: 横方向が進行順の基本。ただし差戻しや再確認の矢印は逆方向にも引ける。
- **文字**: 図形内で折り返し、文字が収まらない場合は編集時に知らせる。色だけに意味を依存しない。

図形や線を単なる飾りにせず、保存データには図形の種類、担当、接続関係、条件、配置をそれぞれ保持する。

## 3. 画面構成

### 3.1 開始画面

| 領域 | 表示・操作 |
| --- | --- |
| 見出し | ツール名と短い説明 |
| 主操作 | 「新しい図を作る」「編集用ファイルを開く」 |
| 復旧案内 | 一時保存がある場合のみ、図の名前と保存時刻を示して「復旧する」「破棄する」 |
| 注意 | 編集用ファイルへの明示的な保存と、一時保存の違いを簡潔に示す |

復旧の確認なしに、古い一時保存で読み込んだファイルを上書きしない。

### 3.2 編集画面

| 領域 | 表示・操作 |
| --- | --- |
| 上部バー | 図の名前、未保存表示、新規・開く・保存・別名保存、元に戻す・やり直す、出力 |
| 左パネル | 図形パレット（開始・終了／作業／判断／帳票／システム）、レーン追加 |
| 中央キャンバス | 縦列レーン、図形、矢印、条件ラベル。スクロールと拡大・縮小 |
| 右パネル | 選択対象の編集。名称、説明、担当、条件、線種など対象に応じた項目 |
| 下部または上部の状態表示 | 保存状態、倍率、操作のヒント、入力や出力に関する警告 |

**配置と接続**: パレットから図形を追加し、キャンバスで動かす。図形を選んで接続操作を始め、接続先を選ぶ。接続中は予定線を表示し、Escで取り消せる。条件ラベルは矢印を選択して右パネルで編集する。接続元・先が分かる選択表示を設ける。

**レーン編集**: レーンの見出しから名称変更・並べ替え・削除を行う。図形があるレーンの削除時は、その図形をどう扱うかを明示してから実行する。

**基本操作**: 図形・矢印の選択、移動、文言の編集、複製、削除、取り消し・やり直しを用意する。Deleteによる削除、Ctrl+Z／Ctrl+Yなどの一般的なショートカットを使えるようにする。ただし文字入力中は入力欄の動作を優先する。

**空の状態**: 初めて開いたときは、画面内に「レーンを追加 → 作業を置く → 矢印でつなぐ」の短い案内を表示する。

### 3.3 出力画面

編集画面から開くダイアログとする。プレビュー、用紙（A4／A3・横向き）、余白、出力形式（PNG／PDF）、背景色を選べる。初期値は横向き、白背景、図全体を1ページに収める設定とする。

図が小さく縮み、文字が読みづらくなる場合や、内容がページ外にはみ出す場合は警告を出す。プレビューと実際の出力で図形・矢印・日本語の改行位置を一致させる。PNGは資料に貼った際に十分な解像度を確保する。

## 4. 代表的な操作手順

### 新規作成

1. 「新しい図を作る」を選び、図の名前を入力する。
2. 担当・部署のレーンを追加し、左からの並びを調整する。
3. 開始、作業、判断、終了の図形を置き、各図形の文言を記す。
4. 矢印でつなぎ、判断の矢印に条件を記す。必要なら流れを合流させる。
5. 帳票やシステムの図形を追加し、関係する作業に付ける。
6. プレビューで読める大きさを確認し、編集用ファイルを保存する。
7. PNGまたはPDFを出力する。

### 再編集と復旧

- 編集用ファイルを開き、図を修正して保存する。
- 未保存の変更がある状態で新規作成・別ファイルを開く・画面を閉じる場合は注意を示す。
- 予期せず終了した場合は、次回起動時に一時保存の名前・時刻を表示し、復旧するか破棄するかを選べる。
- 一時保存の復旧後も編集用ファイルは自動更新されない。明示的に保存する。

## 5. データと保存

編集用ファイルには形式のバージョン、図のID・名前、レーン、図形、接続、補助関係、配置、表示設定を保持する。内部IDは名称とは分ける。接続は座標だけでなく図形IDを参照し、図形を動かしても関係が保たれるようにする。

保存済みファイルを開く際は形式と必須項目を検証し、不正なデータは読み込みを中断して理由を示す。将来の形式変更に備えてバージョンを持つ。ブラウザの一時保存は復旧用とし、図のIDと更新時刻により対象を識別する。編集用ファイルと一時保存の内容が異なる場合は、利用者がどちらを開くか選べるようにする。

ブラウザが既存ファイルへの直接書き込みを許可しない場合もあるため、保存操作は環境に応じてファイルの更新または新しいファイルのダウンロードで実現する。画面には実際に起きた動作を表示する。

## 6. 品質要件

| 項目 | 判定の観点 |
| --- | --- |
| オフライン利用 | 作図・保存・再編集・出力がネット接続なしで行える。実行時に外部CDNを要しない |
| 日本語表示 | Windows 11の一般的な日本語環境で、編集画面とPNG・PDFの文字が欠けない |
| 視認性 | 選択状態と接続先が見分けられ、出力時にレーン名・条件・矢印が読める |
| データ保全 | 未保存表示、復旧候補の確認、無効ファイルの拒否、意図しない上書きの防止 |
| 操作性 | 初めて使う人が短い画面内案内を頼りに、基本図を作れる |
| アクセシビリティ | ボタン名と操作状態が文字でも分かり、色だけで区別しない |

## 7. 受け入れシナリオ

「住民が申請 → 窓口で受付 → 担当者が帳票とシステムを使って確認 → 不備ありなら差戻し、不備なしなら別部署へ引き渡し → 最終処理で合流 → 終了」を、少なくとも3レーンの図として作る。

以下をすべて確認する。

1. 判断の各矢印に別々の条件を付けられ、合流先を設定できる。
2. 帳票・システムと作業を見分けられ、担当間の引き渡しが分かる。
3. 図形を移動しても矢印と補助関係が維持される。
4. 編集用ファイルを保存・再読込しても内容と配置が一致する。
5. 未保存状態から一時保存を復旧でき、保存済みファイルを無断で上書きしない。
6. A4またはA3横のプレビューで文字が読め、PNG・PDFが見た目どおりに出力される。
7. オフラインで上記の操作ができる。

## 8. 実装前に試作で確認する点

- レーンの幅と作業10～30件を1ページに収めた際の文字サイズ。
- 線が交差する図での経路調整の使いやすさ。
- 帳票・システムの補助表示が図を煩雑にしないか。
- ブラウザ別の保存操作とPDF出力の仕上がり。

これらは方式の選択や画面寸法の調整事項であり、上記の利用目的と必須機能は維持する。
