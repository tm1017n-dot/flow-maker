# Windowsへの配置と起動

## 初回インストール

1. `feat/manual-prototype` のZIPをダウンロードし、**ZIP全体を展開**します。
2. 展開したフォルダの `Install.vbs` をダブルクリックします。
3. 最初の画面で `Yes` を選ぶと、`%LOCALAPPDATA%\FlowMakerManual` に配置します。`No` は別の親フォルダの選択、`Cancel` は中止です。
4. 完了後、デスクトップの **Flow Maker Manual** から起動します。スタートメニューにも同名の項目ができます。

管理者権限、PowerShell、追加パッケージ、インストール時の通信は使いません。起動にはHTMLに関連付けられた既定のブラウザを使います。実行したユーザーのフォルダに配置するため、他のユーザーにはショートカットを作りません。

VBSの画面は、Windows Script Hostの文字コードによる文字化けを避けるため英語にしています。ファイルの配置先には日本語や空白を含むパスも使えるよう、FSOと引用符付きの起動を使用しています。

## 同梱物

| ファイル | 役割 |
| --- | --- |
| `Install.vbs` | アプリのコピー、ICO付きの起動ショートカット作成 |
| `Launch.vbs` | 展開フォルダから既定のブラウザで起動 |
| `assets/flow-maker.ico` | Windows用。16〜256pxの7サイズを同梱 |
| `assets/flow-maker.svg` | ブラウザのタブとアプリ内のアイコン |
| `tools/build-icon.py` | 開発用のICO再生成。利用時には実行不要 |

`.lnk`はインストール先の絶対パスを持つため、あらかじめ固定したものを配布せず、実行したPC上で生成します。デスクトップ、スタートメニューの`Flow Maker Manual`フォルダ、配置先フォルダの3か所へ作ります。

インストールせず利用する場合は、展開したフォルダの`Launch.vbs`または`index.html`を開いてください。

## 更新とデータ

更新前に編集中の文書をJSONへ保存し、アプリを閉じてください。新しいZIPを別フォルダへ展開し、`Install.vbs`で同じ配置先を選びます。更新確認の`OK`で、同梱アプリファイルだけを上書きします。JSONやその他の利用者のファイルを削除する処理はありません。

フォルダを移した場合、ブラウザの一時復旧データは引き継げない場合があります。保存したJSONを新しいアプリの「開く」から読み込んでください。

削除する場合は、保存したJSONを残したうえで、配置先フォルダ・デスクトップのショートカット・スタートメニューの`Flow Maker Manual`フォルダを削除します。レジストリや自動起動への登録は行いません。

## 確認範囲

同梱ファイル、ICOの形式とサイズ、VBSのASCII文字コード、コピー対象・起動先・アイコン参照、ファイルがない場合の中止処理を静的に検査しています。Windows上のVBS実行・既定ブラウザでの起動は未確認です。

実機では標準配置、空白・日本語を含む配置先、キャンセル、再インストール、ショートカットからの起動、JSONの再読込を確認してください。
