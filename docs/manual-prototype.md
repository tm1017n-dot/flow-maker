# 業務マニュアルの初回試作

更新日: 2026-09-30
ブランチ: feat/manual-prototype
状態: 操作案内・文書点検・画像・参考資料・改訂情報を追加。実ブラウザ・実際の印刷品質は未確認。

## UIで優先したこと

- 作図・長文編集・文書閲覧を別画面にし、長文を細いプロパティ欄に押し込まない。
- 一覧から項目を選び、広い編集欄で本文を入力する。章の見出しを選ぶと章の設定を編集する。
- 目的・準備・手順・確認・完了を先に置き、注意・例外は折りたたむ。
- 入力中と入力確定時に編集欄を丸ごと再生成せず、フォーカスと次にクリックする項目を保つ。
- 検索・表示切替は保存データや履歴に含めない。
- 非掲載は削除と分け、図形の削除でも本文を保持する。
- 印刷用の文書は白背景とし、操作ボタンを出力に含めない。

## 確認済みのロジック

既存の作図・保存・復旧・出力の回帰チェックに加え、以下を自動チェックした。

- 旧version 1の取込、新version 2の作成・検証・JSON再読込。
- 手順入力、Undo／Redo、入力確定時の編集DOMの保持。
- 図形の名称変更が文書に反映されること。
- 章の追加・移動・削除時の項目保持。
- 図形削除時の本文保持と、対応がないことの表示。
- プレビュー中のDeleteで背後の図形を削除しないこと。
- HTML内の本文エスケープ、編集用ボタンの除外、プレビューと出力のID分離。
- HTML・CSSの構造、重複IDがないこと。

## 今回追加した検証

- 点検結果の操作対象を、本文の入力確定で置き換えないこと。
- 必須項目を入力すると警告が更新されること。
- http／httpsのみリンク化し、スクリプトURLをリンクにしないこと。
- 画像・説明・文書管理情報のJSON復元とHTMLへの埋め込み。
- SVGや不正な画像データ、画像枚数・合計容量、存在しない日付の拒否。
- 画像読み込みの成功・Undo／Redo・削除・説明変更、過大ファイルの拒否。
- 画像読み込み中に別文書へ切り替えると追加を中止し、混入しないこと。
- 手順複製で別ID・番号を割り当て、本文・画像を保持すること。
- 対応切れの再接続で本文を保持し、Undoで元へ戻せること。
- 旧version 2のオプション項目がないデータを読み込めること。
- 画像が多い文書の履歴を容量で制限し、直前のUndo／Redoを保持すること。

自動テストのDOM・画像読込はモックです。実際の画像デコード、ブラウザのメモリ使用量、スクロール位置やフォーカスの使い心地は実機検証が必要です。HTML/CSS構造検査は見た目の確認の代わりにはなりません。

## 実ブラウザでの確認項目

| 条件・操作 | 確認すること |
| --- | --- |
| 1440、1024、768、480px幅／ブラウザ100・125・150・200% | 一覧・入力欄・操作ボタンが重ならず、画面幅に応じて一覧が上段に移る |
| 本文を入力後、すぐ別の手順をクリック | 入力を保持し、1回のクリックで移動できる。ページの位置が不意に変わらない |
| 章・手順・掲載順を編集してUndo／Redo | 本文、章、番号、並びが復元される |
| 実施手順を複数行入力 | 1行1項目で文書に表示され、改行や日本語が欠けない |
| 図形を移動・改名・担当変更 | 文書の作業名・担当・分岐先が連動する |
| 図形削除後に手順を開き、Undo | 本文が残り、対応切れを表示する。Undoで図との対応が戻る |
| ライト／ダークの切替 | 編集欄が読みやすく、プレビュー用紙は白背景を保つ |
| HTMLを別PCへ移してネットなしで開く | 図、本文、目次、分岐先リンクが使え、外部ファイルを必要としない |
| 長文のマニュアルをPDF保存 | 複数ページになり、見出し・本文・図が欠けない。印刷のヘッダー・フッターは無効にする |
| JSONを保存して閉じ、再読込 | フロー・本文・章・番号・文書情報が復元される |

| PNG／JPEGを追加し、説明変更・削除・Undo | 正しい画像が表示され、編集内容が保存後のJSON・HTMLにも残る |
| 本文を入力して点検結果をすぐクリック | 1回で該当手順に移動し、本文が失われない |
| 画像が多い文書で編集・保存・再読込 | 動作時間、メモリ、容量不足の案内、直前のUndoを確認する |

## 残す課題

Word出力、過去版を保持する改訂履歴、複数文書管理は未実装。作成者・確認者・改訂内容は現在版の手入力情報として記録します。印刷の改ページと日本語フォント、各倍率での見た目は実機結果を踏まえて調整する。文章が未記入でも出力は可能で、文書に未記入の案内を含める。
