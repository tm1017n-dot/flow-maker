# Windows 11での確認手順

対象: 最新のindex.html / styles.css / app.jsを同じフォルダに置き、普段使うブラウザでindex.htmlを開く。

本確認は、モックDOMによる回帰チェックでは検証できない描画、マウス、ダウンロード、印刷を対象とする。2026-09-30時点で開発側の実ブラウザ確認は未完了。

| 操作 | 期待する結果 |
| --- | --- |
| サンプルの判断から「あり」の矢印を確認 | 左辺から左側の図形へ向かう。明示的に接続辺を設定した保存データでは、その設定を優先する |
| レーンをクリックして作業を追加 | 選択した担当レーンに置かれる |
| 配置位置を指定し、図形を追加 | 指定した場所に置かれる |
| 「つなぐ」を押してマウスを動かす | 接続元・候補が分かり、予定線が追従する。Escで取り消せる |
| 矢印の編集で接続先を変更 | 図形間の接続が付け替わり、元に戻す操作で復元できる |
| Shift＋クリックで3件選択し、整列・等間隔を操作 | 選択した図形が揃い、担当情報が不意に変わらない。まとめてドラッグできる |
| 帳票の補助線を選び解除 | その補助線のみ消える。元に戻す操作で復元できる |
| 両パネルを折りたたみ、全体表示 | 作図領域が広がり、図全体が収まる |
| 「点検」を押し、警告をクリック | 該当箇所が選択される。警告があっても編集・出力できる |
| 日本語を複数行で入力 | 文字が省略されず、図形が必要な高さへ広がる |
| 図形や矢印を選択したまま出力 | 選択枠・ハンドル・予定線がPNG・PDFに含まれない |
| A4・A3、余白10mm・20mmでプレビューとPDFを比較 | 用紙の縦横比と余白が一致し、1ページになる。印刷画面のヘッダー・フッターは無効にする |
| PDFを100%で表示・印刷 | 日本語・改行・矢印・条件が読め、欠けがない。図全体を確認する |
| A4・300dpiのPNGを保存 | 3508×2480pxを目安に出力される。Word・PowerPointへ貼り付けて読める |
| 保存したJSONを開き直す | 図形・矢印・用紙・余白・解像度設定が復元される |
| 編集直後に保存し、閉じて再起動 | 保存直後の古い予約処理で不要な復旧候補が再作成されない |
| 未保存の変更がある状態で閉じ、再起動 | 復旧用データを選んで開ける。保存済みJSONは勝手に変更されない |
| 不正なJSONを開く | 理由を示し、編集中の図を維持する |

確認時はブラウザ名・バージョン、Windowsの表示倍率、用紙・印刷倍率と、失敗した操作を記録する。

## 矢印のドラッグと画面幅の追加確認

| 操作・条件 | 期待する結果 |
| --- | --- |
| 矢印の縦の線を左右、横の線を上下にドラッグ | 線の経路が動き、図形との接続は維持される |
| 矢印を選び、両端の丸を図形の周囲へドラッグ | 接続辺と辺の中の位置が変わる。判断の菱形でも端点が輪郭上に乗る |
| ラベルをドラッグ | ラベルだけが移動し、経路と接続先は維持される |
| 上記の変更後に元に戻す・保存・再読込 | 元の位置へ戻せ、保存データから接続端の位置も復元できる |
| 条件ラベルがある矢印を選択 | 中央の編集用丸が条件の文字を隠さない |
| キャンバスの空白をドラッグ | 画面だけが移動し、図の保存状態は変わらない |
| 幅1440、1024、768、480px、Windows表示倍率100%・125% | 保存ボタン、表示コントロール、作図補助が折り返して収まり、ページ自体に不要な横スクロールが出ない。キャンバス内のスクロールは可能 |
| パネルを隠す・表示する | 戻すためのボタンが残り、作図領域が広がる |
| 操作ガイド・点検・出力ダイアログを狭い画面で開く | 内容をスクロールでき、閉じるボタンが画面外へ固定されない |

2026-10-01: HTMLの構造、コントロールの参照、操作ロジックの回帰チェックは通過。実ブラウザの画面は開発環境のポリシーで開けず、上記の見た目とマウス操作の実機確認は未完了。

## ブラウザの拡大・縮小の確認

Windowsの表示倍率、ブラウザの倍率、「図の倍率」を別々に記録する。「図の倍率」は100%にして始め、ブラウザの倍率だけを変更する。

| 条件・操作 | 期待する結果 |
| --- | --- |
| ブラウザ倍率67%、80%、100%、125%、150%、175%、200%を順に変更 | 図形ボタンのアイコン・「＋」が潰れず、説明文が折り返す。サイドバーの下の項目へスクロールできる |
| 有効幅1101／1100px、761／760px、401／400pxの前後を確認 | 編集パネルは幅1100px以下で下段、図形パネルは760px以下で上段2列、400px以下で1列になる。図形が追加できる |
| 高さ700px以下、ブラウザ倍率200%で操作 | ページをスクロールして保存・出力・編集項目へ到達できる。キャンバスの空白部分をドラッグして図を移動できる |
| 図形パネル・編集パネルを隠してから再表示 | 表示ボタンが残り、パネル内をスクロールできる。図の内容・保存状態は変化しない |
| 長い図の名前、図形説明、未保存表示を確認 | テキストがアイコンやボタンに重ならず、ページに不要な横スクロールが出ない |
| 拡大後に「全体表示」を押す | 現在の作図領域に図全体が収まる。「図の倍率」だけが変わる |
| 拡大中に出力・点検・操作ガイドを開く | ダイアログ内をスクロールでき、閉じるボタンまで到達できる |

今回の変更ではCSSの配置指定、HTML構造、既存操作の回帰チェックを確認済み。上記の実ブラウザ表示確認は未完了。
