# 基本機能確定版 v1.0 のブラウザ確認手順

対象: リポジトリの最新のindex.html、styles.css、app.jsを同じフォルダへ置き、Windows 11のChrome／Edgeでindex.htmlを開く。

2026-10-01時点で、Nodeによる操作・保存・読込・出力処理の回帰チェックとHTML/CSSの構造確認は通過しています。実ブラウザの描画・マウス・ダウンロード・印刷確認は未完了です。開発環境には利用可能なChromiumがなく、クラウドブラウザでのローカル画面へのアクセスもブロックされています。

ブラウザ名・バージョン、ウィンドウサイズ、Windowsの表示倍率、ブラウザの倍率、「図の倍率」、出力条件を記録します。

## レイアウト

| 条件・操作 | 期待する結果 |
| --- | --- |
| 1440×900、1280×720、1024×768、768×1024、480×800px | サイドバーのアイコン・「＋」が潰れず、説明文は折り返す。不要なページ横スクロールがない |
| ブラウザ倍率67%、80%、100%、125%、150%、175%、200% | 文字やボタンが重ならない。収まらない図形項目・編集項目へスクロールして到達できる |
| 有効幅1101／1100、761／760、401／400 CSS px前後 | 編集パネルが下段、図形パネルが上段2列／1列へ切り替わる。キャンバス枠は最低680pxの高さを維持する |
| 高さ700px以下、ブラウザ200% | ページをスクロールでき、キャンバスやダイアログの下部へ到達できる |
| パネルを隠して再表示 | 戻すボタンが残り、図の内容・保存状態は変わらない |
| 長い図名・日本語複数行を入力 | 文字が省略されず、図形が必要な高さへ伸びる。UIの文字が操作ボタンと重ならない |
| 倍率やパネル表示を変更して「全体表示」 | 現在の作図領域に図が収まる。ブラウザの倍率は変わらない |

## 操作・状態

| 操作 | 期待する結果 |
| --- | --- |
| 担当レーンを選び、図形を追加 | そのレーンへ追加される。「配置位置を指定」も使える |
| 配置・接続中にJSONを開く、新規作成、Undo | 前の配置・接続モードやマーカーが残らない |
| 「つなぐ」でマウスを動かし、Esc | 予定線・候補が追従し、Escで解除される |
| 矢印の線・両端の丸・ラベルをドラッグ | 経路・接続位置・ラベルがそれぞれ動き、図形との接続を維持する |
| 接続元・先を編集、矢印を自動配置へ戻す | 指定が反映され、Undoで復元できる |
| 複数選択・整列・等間隔・主選択のShift解除 | 選択を維持して移動・整列でき、残った図形が編集対象になる |
| レーン並べ替え・中間レーン削除・Undo | 図形と、両端が同じ量移動する手動経路が追従し、Undoで戻せる |
| 帳票の破線を選び解除 | その破線だけが消え、Undoで戻せる |
| 空白をドラッグ | 画面だけ動き、図の保存状態は変わらない |
| 点検の警告をクリック | 該当箇所を選び、編集パネルが開く |
| ダイアログ中にDelete／Ctrl＋Z | 背後の図を削除・変更しない。閉じるボタンへ到達できる |

## 保存・出力

| 操作 | 期待する結果 |
| --- | --- |
| 不正なJSONを開く | 理由を示し、図と編集中のモードを維持する |
| JSON保存・開き直し | 図形、矢印の端点と経路、ラベル位置、用紙設定が復元される |
| 未保存で終了して再起動、保存直後に終了 | 未保存データは復旧でき、保存後に古い一時保存が復活しない |
| 選択・接続中にPNG／PDF出力 | 編集枠・ハンドル・予定線が含まれない |
| A4／A3、余白10／20mmのプレビュー・PDF | 縦横比・余白が一致し1ページになる。日本語と矢印が欠けない |
| A4・300dpiのPNG | 約3508×2480pxで出力され、文書に貼り付けて読める |
| PNG出力中に用紙・解像度を変更 | 出力開始時の条件で作られ、完了後に再出力できる |

この手順の実機結果が揃うまでは、ブラウザ上の見た目・印刷品質について確認済みとは扱いません。
